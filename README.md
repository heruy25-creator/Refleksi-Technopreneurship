# ✈️ Refleksi Technopreneurship — Aviation Blue

Website interaktif untuk menampilkan refleksi pembelajaran **Technopreneurship** dengan tema visual aviasi dan dominasi warna biru.

Halaman ini mengemas materi pembelajaran ke dalam tab-tab terpisah agar lebih mudah dibaca, dijelajahi, dan dipresentasikan.

## ✨ Fitur

- **Desain bertema aviasi** dengan header bergambar pesawat dan nuansa biru.
- **Navigasi berbasis tab** untuk berpindah antar topik pembelajaran.
- **Gambar tematik** pada setiap tab dan area konten.
- **Tab Character** menampilkan foto Elon Musk sebagai ilustrasi tokoh technopreneur.
- **Pencarian materi** untuk membantu menemukan bagian tertentu.
- **Mode terang dan gelap**.
- **Pengaturan ukuran teks**.
- **Fitur salin konten**.
- **Navigasi bagian** dan indikator progres membaca.
- **Desain responsif** untuk desktop maupun perangkat mobile.

## 📚 Topik Pembelajaran

| Tab | Topik |

| Concept | Konsep technopreneurship |
| Character | Karakter technopreneur |

## 🚀 Menjalankan Proyek

Proyek ini berupa halaman HTML, sehingga tidak memerlukan proses instalasi atau build.

1. **Clone repository**
   ```bash
   git clone https://github.com/USERNAME/NAMA-REPOSITORY.git
   ```
2. **Masuk ke folder proyek**
   ```bash
   cd NAMA-REPOSITORY
   ```
3. **Buka file HTML** `Refleksi_Technopreneurship_Aviation_Blue.html` menggunakan browser seperti Google Chrome, Microsoft Edge, atau Mozilla Firefox.

Alternatifnya, unduh file HTML dari repository lalu buka langsung di browser.

## 🌐 Publikasi dengan GitHub Pages

Website statis ini dapat dipublikasikan menggunakan GitHub Pages.

1. Buka repository di GitHub.
2. Pilih **Settings** → **Pages**.
3. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu proses publikasi selesai. GitHub akan menampilkan URL website pada halaman Pages.

> Jika ingin halaman tampil langsung pada alamat utama GitHub Pages, pertimbangkan untuk mengganti nama file HTML menjadi `index.html`.
